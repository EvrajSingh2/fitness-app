# Fitness App (MERN) - Starter
🚀 Built My Full-Stack Fitness Tracker App!

I’m excited to share my latest project — a full-stack fitness tracking web application that helps users monitor their health, workouts, and nutrition goals.

💪 Key Features:

User Authentication (Signup/Login with JWT & bcrypt security)

Personalized Dashboard displaying:

Daily calorie & protein needs (auto-calculated using gender, age, weight, height, training level, and fitness goals)

Weight tracking graphs 📊 (Recharts)

Training level and expected goal tracking

Update Profile section with password change & unit flexibility (cm/inches)

Add daily logs for weight, calories, and workouts

Food tracking with automatic calorie updates 🍎

⚙️ Tech Stack Used:

Frontend: React.js, Recharts, CSS3 (custom responsive UI)

Backend: Node.js, Express.js, JWT Authentication, bcrypt

Database: MongoDB (Mongoose ODM)

Deployment: (To be hosted soon on Render / Vercel)

🔮 Future Enhancements:

Integration with a public food API for calorie & macronutrient lookup

AI-based personalized fitness recommendations 🧠

Workout scheduling and reminders

Integration with wearable fitness devices

Dark mode & mobile PWA support
